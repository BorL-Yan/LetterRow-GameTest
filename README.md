# Word in chine — тестовые сборки

WebGL-сборка игры для проверки на телефоне. Сайт: **https://borl-yan.github.io/LetterRow-GameTest/**

## Как обновить сборку

**Из Unity (одной кнопкой):** `Tools → Build → WebGL → GitHub Pages → Build And Push`.
Скрипт соберёт игру с шаблоном `Mobile`, положит её в эту папку и сделает commit + push.
Через 1–2 минуты GitHub Pages обновит сайт.

**Вручную:** соберите WebGL в Unity (шаблон *Mobile*, Compression *Gzip* + *Decompression Fallback* —
их ставит `Tools → Build → WebGL → GitHub Pages → Apply Web Settings`) и замените содержимое репозитория
файлами сборки (`index.html`, `Build/`, `TemplateData/`, …). README.md и .nojekyll не трогайте.
Через сайт GitHub можно загрузить файлы до 25 МБ, через git — до 100 МБ.

## Тест на телефоне

- Экран заполняется целиком; на телефоне 1080×2400 игра рисуется в 1080×2400 (настоящие пиксели экрана).
- На компьютере игра показана в рамке 9:20, как на таком телефоне.
- **Иконка на рабочий стол:** Android/Chrome — кнопка «Добавить на экран» вверху или меню ⋮ → «Добавить на гл. экран»;
  iPhone/Safari — «Поделиться» → «На экран „Домой“». С иконки игра открывается во весь экран, без адресной строки.
- Новая сборка подхватывается сама: страница сверяет `version.json` и перезагружается на свежую версию.
- `?info` — показать реальное разрешение рендера; `?dpr=1` — рендер в пониженном разрешении (проверка FPS).
